# 복구 경로와 누적 사람검증 점수 · 2026-10-29

## 현재 정책

- 프론티어 미해결·불확실: 사람검증 점수 +1.
- 독립 검토 후 낮은 비교 점수·근거 부족·미해결 충돌: 사람검증 점수 +1을 앞선 점수에 추가.
- 잘못된 가지·다음 하위 후보 진행 불가로 실제 상위 복구: 사람검증 점수 +1.
- 매 가산 직후 누적 2점 이상이면 이후 모델 호출 없이 사람 검수.

복구 +1 뒤 프론티어 +1이면 2점에서 멈추고 독립 검토를 생략한다. 프론티어 +1 뒤 독립 검토 미해결 +1이면 누적 2점으로 사람 검수에 도달한다. 낮은 비교 점수와 미해결 충돌은 같은 독립 검토 사건으로 1점만 기록한다.

같은 상품·사건 유형·원인은 중복 가산하지 않는다. 단순한 낮은 점수는 다음 모델로 보내는 사유이며, 실제 잘못된 분기·막힌 하위 경로가 있을 때 복구 점수를 더한다. 데모 복구는 같은 부모 아래 대체 분기를 한 번 탐색한다. 사진 불량이나 복구 후보 소진은 2점 미만이어도 별도 보류한다.

## 화면과 검사

주황 복귀·재진입 화살표, 상품별 누적 사유, 검수 대기 목록을 연결했다. 세 가지 예시 버튼의 마지막 상태는 독립 비교 해결 시 1점 분류 완료, 복구 후 프론티어 미해결 시 2점 검수, 독립 비교 미해결 시 2점 검수다. 이전·다음 장면과 초기화에서도 당시 점수만 표시한다.

`test-recovery-score.cjs`는 중복 가산 방지, 독립 사건 합산, 점수 스냅샷 보존, 형제 분기, 복구 횟수 한도, 예시 버튼·초기화를 검사한다. `test-cascade.cjs`는 2점 도달 뒤 추가 호출 생략과 독립 비교의 +1 추가를 검사한다. 브라우저에서 세 사례의 점수·최종 상태와 0점 초기화를 확인했다.

오른쪽의 별도 사람 검수 구역에는 현재 분류 위치 → 수평 이동 통로 → 도착 구역의 3장면 이동을 연결했다. 검수 전환은 점수 도달 즉시 적용하며, 이동하는 동안 추가 모델을 호출하지 않는다. `검수 전환 = 이동 중 + 도착`으로 집계하고, 도착한 상품만 구역의 목록에 표시한다. 이동 화면은 대표 상품을 보여 주며 수량은 전체 상품 기준이다. 동작 줄이기 설정에서는 이동 없이 바로 도착한다.

기존 전체 검수 목록은 점수 우선·동점 전환 순서다. 새 구역의 목록은 최근 도착 상품을 보여 주며 선택 상품을 먼저 표시한다. 사진 불량·복구 실패로 보류된 0~1점 상품은 `별도 보류`로 구분한다. `2점 → 검수 이동 재생`과 `분야 확대 → 사람 검수 구역`으로 이동과 도착을 확인할 수 있다.

`test-human-sector.cjs`에서 통로 간 간격, 출발·우회·도착 좌표, 즉시 중단, 정확한 집계, 별도 보류 표시, 장면 되감기·초기화, 동작 줄이기를 확인했다. 자동 확장 6개 설정에서도 마지막 검수 이동의 도착까지 시간축에 포함한다.

사람이 확정·수정하거나 정답을 학습에 반영하는 기능은 없다. 모든 모델 응답·점수·복구 결과는 고정된 가상 사례이며 실제 확신도 보정·API 호출·정확도 측정은 하지 않았다.
