# 복구 경로와 누적 검수 점수

## 동작

- 불확실한 후보를 만나면 상위로 복귀 → 대체 후보 비교 → 후보 재진입 → 근거 토론을 한 번씩 진행한다.
- 복구 이력은 +1. 토론 실행만으로 점수를 더하지 않고, 토론 후에도 충돌하면 +1. 최종 예시 확신 점수가 60 미만이면 충돌 +1 대신 +2를 기록한다.
- 합계 2점에 도달하면 현재 결과 표시 후 사람 검수 대기로 이동한다. 같은 상품·단계·원인·사건 유형은 중복 가산하지 않는다. 낮은 확신 +2는 같은 원인의 충돌 +1을 대체한다.
- 0~1점은 자동 확정의 충분조건이 아니다. 최종 이미지 근거와 의견 일치 조건을 유지하며, 사진 불량은 점수와 별개로 보류한다.
- 각 장면에 당시 점수·사유를 저장하므로 뒤로 이동하거나 초기화하면 미래 사건이 먼저 표시되지 않는다.
- 검수 대기 목록은 점수 우선, 같은 점수는 도착 순서로 정렬한다. 사람의 확정·수정·학습 반영 기능은 이 데모의 범위에 포함하지 않는다.

## 화면

주황색 복귀·재진입 화살표, 상품별 점수와 누적 사유, 검수 대기 목록을 연결했다. `복구 후 통과 / 복구 후 충돌 / 낮은 확신` 버튼은 실제 500개 가상 상품 중 해당 사례의 장면으로 이동한다. 이후 재생하거나 한 장면씩 진행할 수 있다. 기존 판매자 정보·자동 확장·직행 기준·모델 로고·가상 토론 조작은 유지했다. 하단의 반복 설명은 참고 링크를 가진 접기 영역으로 줄였다.

## 검증 범위

- 기존 `test-text-first.cjs`, `test-direct-route.cjs`, `test-seller-enrichment.cjs` 통과.
- `test-recovery-score.cjs`: 동일 원인 중복, +1에서 +2로 대체, 2점 중단, 사진 불량 보류, 복구 1점 통과, 별개 단계의 누적, 장면별 점수, 초기화, 화면 경계, 500개 보존 및 자동 확장 설정별 마지막 상태 확인.
- 실제 브라우저에서 복구 1점 통과와 복구+충돌 2점 검수 이동 확인. 390×844 모바일 화면에서 페이지 가로 넘침 없이 버튼·점수·전체 분류도 표시 확인.

모든 상품·후보·점수·재탐색·토론 결과는 설명을 위한 고정 시나리오다. 일부 상품의 재검토 후 87점은 복구 성공 예시로 지정한 값이며 모델 측정값이 아니다. 실제 검색·모델 호출·정확도·비용 절감은 검증하지 않았다. 별도의 로고 토론 예시는 주 시뮬레이터의 상품 상태를 변경하지 않는다.
