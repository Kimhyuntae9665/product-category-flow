# 복구 경로와 누적 검수 점수 · 2026-10-29

## 현재 정책

- 프론티어 미해결·불확실: +1.
- 독립 검토 후 낮은 비교 점수·근거 부족·미해결 충돌: 앞선 점수에 +2를 추가.
- 잘못된 가지·다음 하위 후보 진행 불가로 실제 상위 복구: +1.
- 매 가산 직후 누적 2점 이상이면 이후 모델 호출 없이 사람 검수.

복구 +1 뒤 프론티어 +1이면 2점에서 멈추고 독립 검토를 생략한다. 프론티어 +1 뒤 독립 검토 +2이면 3점이다. 이전 정책의 '충돌 +1 대신 낮은 확신 +2'는 현재 누적 정책에 적용하지 않는다.

같은 상품·사건 유형·원인은 중복 가산하지 않는다. 단순한 낮은 점수는 다음 모델로 보내는 사유이며, 실제 잘못된 분기·막힌 하위 경로가 있을 때 복구 점수를 더한다. 데모 복구는 같은 부모 아래 대체 분기를 한 번 탐색한다. 사진 불량이나 복구 후보 소진은 2점 미만이어도 별도 보류한다.

## 화면과 검사

주황 복귀·재진입 화살표, 상품별 누적 사유, 검수 대기 목록을 연결했다. 세 가지 예시 버튼의 마지막 상태는 1점 분류 완료, 2점 검수, 3점 검수다. 이전·다음 장면과 초기화에서도 당시 점수만 표시한다.

`test-recovery-score.cjs`는 중복 가산 방지, 독립 사건 합산, 점수 스냅샷 보존, 형제 분기, 복구 횟수 한도, 예시 버튼·초기화를 검사한다. `test-cascade.cjs`는 2점 도달 뒤 추가 호출 생략과 독립 비교의 +2 추가를 검사한다. 브라우저에서 세 사례의 점수·최종 상태와 0점 초기화를 확인했다.

검수 대기는 점수 우선·동점 도착 순서다. 사람이 확정·수정하거나 정답을 학습에 반영하는 기능은 없다. 모든 모델 응답·점수·복구 결과는 고정된 가상 사례이며 실제 확신도 보정·API 호출·정확도 측정은 하지 않았다.
