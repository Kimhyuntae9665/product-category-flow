# 첫 화면 설계와 검수 · 2026-10-29

URL을 열면 **텍스트 → 이미지 전용 분류기 1개 → 프론티어 → 독립 검토**와 각 단계의 조기 종료를 먼저 읽도록 구성했다. 과제 500만 상품·1만 카테고리와 데모 500상품·10대분류, 정확도와 총비용의 관계를 상단에 유지했다.

## 정보 배치

- 주 흐름 4단계는 PC에서 가로, 모바일에서 세로로 연결한다. 해결 경로는 최종 분류 영역으로 모인다.
- 공통 규칙 2개는 바로 아래에 둔다: 경로 복구 +1, 누적 2점 이상이면 이후 호출 생략·사람 검수.
- EfficientNet-B0와 ConvNeXt-Tiny의 같은 상품 비교는 별도 띠에 둔다. 도입 전 선택 실험과 운영 중 한 모델 사용을 구분한다.
- 모델·점수의 상세 설명은 접기 영역에 둔다. 현재 점수는 가상 값이며 실제 학습·보정·비교는 미실시다.
- 독립 검토 장면은 A/B/C가 같은 사진·글·분류 기준으로 먼저 각각 판정하고 답을 공개한 뒤 비교한다. 미리 작성한 예시이며 특정 모델의 이미지 처리 성능을 주장하지 않는다.
- 2026.10.28 PAL 텍스트 설계 검토 기록은 과거 기록으로 접어 보존했다. 현재 상품의 모델 실행·선정 기록과 구분한다.
- 하위 트리의 표시는 '분류 경로·층'이다. 최종 후보 확인 후 이동을 층마다 새로운 모델 호출로 표시하지 않는다.

## 참고와 구현 범위

[UI reference kit](https://github.com/Kimhyuntae9665/ui-reference-kit)의 32개 목록과 두 이미지 목차를 검토했다. 이번에는 **12번 분기·병렬 흐름**과 **15번 상태·전환 조건**의 정보 구조를 선택했다. 후보 설명·원본 이미지·개념 SVG를 비교했고, 기존 HTML/CSS로 읽기 순서와 분기·종료 규칙을 표현했다. 원작 화면이나 브랜드 이미지를 복제하지 않았다.

Lucide 12종 아이콘의 라이선스 고지를 HTML에 포함했다. 과거 검토의 Lobe 브랜드 로고 3종과 라이선스·출처를 보존했다. 자체 도형·상품 SVG와 인라인 자산으로 실행 시 외부 요청이 필요 없다.

## 확인 결과

- 7개 Node 검사 통과: 텍스트 우선, 최종 직행, 판매자 보강, 복구 점수, 분류 트리, 새 단계별 정책, 검수 구역 이동.
- 근거 충족 시 다음 모델 생략. 이미지 전용 분류기는 한 번만 사용. 복구+프론티어 2점이면 독립 검토 없음.
- 첫 판정의 동일 입력·동료/앞선 답 비노출, 답을 모은 뒤 비교, 낮은 비교 점수 +2 추가 검사.
- 500개 보존, 10개 대분류·66개 노드·38개 최종 분류. 기본 338개 완료·162개 검수는 합성 시나리오 결과.
- PC 1280×720과 모바일 390×844에서 연결선·줄바꿈·카드 넘침 확인. 모바일 페이지 가로 넘침 없음. 임시 화면 크기 설정 원복.
- 첫 화면 재생의 실제 시뮬레이션 이동·전체 맞춤, 1/2/3점 예시, 마지막 장면·초기화, 독립 검토의 1점 분류/3점 검수와 조건 변경 초기화 확인.
- 브라우저 오류·경고 로그 없음. 현재 첫 화면은 `assets/overview.jpg`에 보존.

실제 모델·API 호출, 두 이미지 모델의 학습·벤치마크, 확신도 보정, 실제 처리량·비용·정확도 측정은 이번 변경에 포함하지 않는다.

## 직행 통로와 검수 구역 분리

2026.10.29 추가 수정. 기존 4,200px 카테고리 배치는 유지하고 전체 공간을 5,000px로 넓혔다. 카테고리 오른쪽 끝 4,129px와 직행 상품 왼쪽 4,276px 사이에 147px를 확보했다. 직행 중심 4,320px, 검수 이동 통로 4,440px, 사람 검수 구역 4,510~4,960px로 나누었다. 직행 제목도 이동 티켓 위의 여백으로 옮겼다.

사람 검수 구역은 전환·이동 중·도착 수, 대표 상품 도착 공간, 도착 대기 목록으로 구성했다. PC에서 P012가 14장면에 2점으로 전환되고 16장면에 이동 통로를 지나 17장면에 도착하는 것을 확인했다. 모바일 390×844에서는 검수 구역 확대 배율을 맞춰 좌우 경계와 대기 목록이 잘리지 않도록 했으며, 실제 페이지 폭과 스크롤 폭이 모두 375px였다. 초기화 후 세 집계는 모두 0, 브라우저 경고·오류는 없었다.
