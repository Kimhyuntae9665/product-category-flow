# 첫 화면 설계와 검수 · 2026-10-28

과제 검토자가 URL을 열자마자 **텍스트 우선 분류 → 근거가 충분하면 최종 분류 → 애매하면 추가 검토 → 미해결은 사람 확인**이라는 설계를 읽을 수 있도록 구성했습니다.

- 첫 화면: 핵심 문장, PC 기준 330×88px 재생 버튼, 분기 인포그래픽. 재생 버튼은 실제 분류 화면으로 즉시 이동하고 화면의 높이·너비에 맞춰 전체 경로를 축소합니다. 진행 숫자와 재생/정지/초기화는 기존 500개 가상 상품 엔진을 공유합니다.
- 가상 토론: 상품 한 개의 후보 제안, 반론, 근거 확인을 3단계·9개 발언으로 살펴봅니다. 실제 PAL 모델의 로고·이름으로 발언자를 구분하고 재생·정지·다음 발언·단계 선택을 지원합니다. 정보 충분/부족 두 상황의 대화는 미리 작성한 설명용 예시입니다. 실제 모델 호출이나 500개 상품의 실행 기록으로 표시하지 않습니다.
- 상세 시뮬레이션: `전체 보기`에서는 설정 영역을 잠시 숨기고 모든 분류 경로를 한 화면에 맞춥니다. `크게 보기`는 설정 영역과 기존 배율을 복원하며, 좁은 화면에서 큰 분류도는 내부 가로 스크롤로 읽습니다. 배율 전환으로 진행 장면·재생 상태·상품의 분류 결과가 바뀌지 않습니다.
- 표현: Qwen·NVIDIA·Cohere·Gemini의 원본 로고와 모델명·호출 서비스를 표시합니다. Qwen·Nemotron·North의 발언 차례에 맞춰 모델 카드와 말풍선을 강조하고, 이전 의견에 답하는 관계를 표시합니다. 실제 설계 검토 참여 상태와 가상 상품 대화를 구분합니다. Gemini는 503 오류로 참여하지 못했음을 표시합니다.

## 참고한 정보 구조

[UI reference kit](https://github.com/Kimhyuntae9665/ui-reference-kit)의 32개 방향을 비교하고 12번(분기와 병렬), 18번(조작하는 설명), 14번(근거 관계)을 선택했습니다. 역할과 결과로 연결되는 흐름을 가져오고, 원작 화면·브랜드는 복제하지 않았습니다.

[Lucide Static](https://lucide.dev/guide/static) 1.63.0의 11종 아이콘과 [Lobe Icons](../assets/model-logos/README.md)의 4종 브랜드 로고를 사용합니다. 라이선스 고지는 HTML 내부에 포함하고 원본 로고·출처·MIT 라이선스를 저장소에 보존했습니다. 제품과 연결선은 자체 SVG입니다. 화면은 외부 폰트·스크립트·이미지 다운로드 없이 작동합니다.

## PAL 설계 검토의 범위

설계안과 기존 재생 코드 발췌문을 무료 4개 모델 경로에 전달했습니다. Qwen3.8 27B(Groq), Nemotron 3 Ultra(OpenRouter), North Mini Code(OpenRouter)는 독립 검토와 상호 비평을 완료했습니다. Gemini 3.8 Flash는 제공사 503 오류로 완료되지 않았으며 재시도하지 않았습니다.

검토는 텍스트 기반으로, 최종 화면을 보거나 실행한 검증이 아닙니다. 버튼의 크기, 과정 노출, 시뮬레이션 표시, 화면 검수가 필요하다는 의견을 실제 구현·브라우저 결과와 대조했습니다. 설계안에 이미 예정된 변경을 기존 코드의 결함으로 다시 지적한 항목도 있었으므로 모델 간 동의를 품질 인증으로 사용하지 않았습니다.

모델 로고 추가에서는 기존 응답을 다시 읽어 ID·참여 상태·사용량을 확인했고 새 추론은 호출하지 않았습니다. 실제 응답의 한국어 요약은 펼치기 영역에, 미리 작성한 상품 대화는 별도 영역에 표시합니다. 상품의 사진은 별도 전처리 결과를 텍스트로 전달했다는 가정이며, PAL에 이미지를 보내거나 각 모델의 이미지 처리 성능을 검증하지 않았습니다.

## 확인한 동작

- 기존 3개 Node 시나리오 검사 통과: 텍스트·이미지 경로, 최종 직행, 판매자 정보, 자동 확장, 최종 바스켓.
- 첫 화면 재생/정지/완료 후 재생/초기화, 진행 숫자 동기화, 가상 토론의 두 결과와 단계 초기화 검사.
- 첫 화면 재생 버튼의 자동 이동·전체 축소·재생, 확대/축소 시 장면 유지 검사. 1280×720 PC와 390×844 모바일에서 모든 분류 경로의 화면 내 표시와 페이지 가로 넘침 없음 확인.
- 9개 발언 순서와 카드·말풍선의 일치, 자동 재생 종료, 조건 변경 시 재생 정지·첫 발언 복귀, 기존 상품 상태 불변 검사.
- 데스크톱과 모바일에서 줄바꿈·잘림·페이지 가로 넘침, 접기/펼치기 및 분류도 내부 스크롤 확인.
- 키보드 Enter로 재생, 움직임 줄이기 설정에서 흐름선 애니메이션 정지 확인.

이 검수는 웹 데모의 동작과 설명을 확인합니다. 실제 상품 정확도, 500만 개 처리량, 비용, 판매자 참여율이나 실제 모델 간 토론 품질을 측정하지 않습니다.
