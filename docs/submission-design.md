초기 호출비용을 학습 자료와 자체 모델로 연결한다는 의도를 담았다. 프론티어 답은 임시 정답 후보이며 표본·충돌·희귀 분류 검수와 사람의 수정 결과를 거쳐 선별한다. 전환 기준은 데이터 수량뿐 아니라 분류별 다양성, 상품 단위의 학습·검증·최종 평가 분리, 정확도·오분류·자동 처리·사람 검수율, 학습·서버·호출·수정 비용이다. 이미지로 구분할 수 없는 규격·성분·호환성은 텍스트와 추가 검토 경로를 유지한다.

PyTorch 전이학습 가이드와 Google Research의 Noisy Student 연구 소개를 2026.10.29 직접 확인했다. 사전학습 특징 재사용과 예측 라벨 활용의 방법만 참고했으며, 해당 연구 결과를 이 서비스의 성능으로 인용하지 않았다. 현재 시뮬레이션의 데이터 수집·학습·성능 및 비용 평가 완료를 뜻하지 않는다는 표시를 제목 옆과 본문 아래에 넣었다.

PC 기본 화면 1280×720과 모바일 390×844에서 제목·전이학습 설명·네 단계·전환 기준을 확인했다. PC는 네 열, 모바일은 한 열로 표시하며 모바일 페이지·스크롤 폭은 모두 375px였다. 전환 기준 접기 영역의 열기·닫기를 확인했고, 브라우저 경고·오류는 0건이다. 임시 뷰포트를 복원했다. 화면 캡처는 `assets/future-improvements.png`다. 정적 HTML/CSS 추가이며 기존 시뮬레이션 스크립트는 변경 전과 동일함을 비교했다.

## 개선 흐름 애니메이션과 사람검증 점수 명칭 · 2026.10.29

기존 추후 개선 방향에 24초 길이의 HTML/CSS/SVG 애니메이션을 넣었다. 프론티어 판단 자료 축적 → 검수 자료 선별 → 전자제품·의류·반려동물용품 모델의 학습·별도 평가 → 통과한 분야부터 점진적 전환을 보여준다. 미리 작성한 흐름이며 실제 데이터 수집·학습·모델 호출은 없다. 자료 18묶음과 소형 모델 비중 0→75%는 설명용 가정이며 학습 기준·정확도·비용 절감률이 아니다. 새 분야와 어려운 상품은 프론티어·추가 검토 경로에 남는다.

재생·일시정지·다시 재생·초기화, 네 장면 선택, 진행 막대, 동작 줄이기를 제공한다. 자동 시작하지 않고 사용자가 재생하며, 페이지가 숨겨지면 멈춘다. OS의 동작 줄이기를 감지하면 최종 정지 장면으로 열고, 직접 선택한 동작 줄이기에서는 현재 장면과 장면 버튼을 유지한다. 이동 점은 없애되 짧은 색·불투명도 전환은 유지한다. 확인용 URL의 futureAt 값은 0~24초로 제한되며 futureReduce=1로 정지 경로를 볼 수 있다.

상단 가산 조건을 '불확실하거나 분류하지 못하면 사람검증 점수 +1', '낮은 보정 점수·충돌 미해결 시 사람검증 점수 +2'로 바꿨다. 복구 +1, 누적 2점 이상 중단, 프론티어 배지, 독립 검토 결과, 상품 상세와 사건 기록에도 사람검증 점수 명칭을 사용했다. 모델 신뢰도와 달리 사람이 확인해야 할 필요성을 누적하는 규칙 점수임을 설명했다. 점수 계산·분류 경로·임계값은 바꾸지 않았다.

검증: test-future-learning, test-blind-review, test-recovery-score, test-direct-route 통과. 자료 누적과 평가 전 전환 방지, 비중 합계 100%, 재생·정지·초기화·장면 이동, 동작 줄이기와 숨긴 탭 정지, 기존 분류 시뮬레이션 비변경을 확인했다. 문구 변경에 따른 기존 두 테스트의 예상 문구를 갱신했다.

PC는 3개 모델이 전환 가능한 상태에서 프론티어 25%·소형 모델 75%, 중간 장면은 분야별 전환·평가·학습 상태가 동시에 보였다. 모바일 390×844에서 흐름을 세로로 배치했고, 재생 제어·동작 줄이기·초기화를 확인했다. 점수 문구는 PC 1280×720, 중간 폭 1024×768, 모바일 390×844에서 확인했다. 페이지와 스크롤 폭은 각각 1265/1265, 1009/1009, 375/375px로 가로 넘침이 없었고 경고·오류는 0건이었다. 임시 뷰포트는 복원했다.
