# 10개 대분류와 여러 하위 분기

## 이번 변경

- 과제의 실제 규모인 상품 500만 건·카테고리 1만 개와, 이 화면의 상품 500개·대분류 10개를 상단에서 구분한다.
- 애니메이션의 작동 구조를 보여주기 위해 규모를 줄인 축소판임을 명시한다.
- 사용자가 제시한 상품당 예산 20원과 `정확도 = 돈`이라는 설계 관점을 함께 표시한다. 실제 비용 계산이나 정확도 측정 결과는 아니다.
- 반려동물용품을 추가하고, 의류의 상의·하의, 의약품의 일반의약품·전문의약품, 가정용품의 생활용품·청소용품 등 같은 층의 분기를 만든다.
- 각 상품의 목표 경로와 최종 바스켓을 연결한다. 하위 분류는 장식용 이름이 아니라 해당 상품의 이동 경로로 사용한다.
- 기존 판매자 정보 보강, 텍스트 우선·최종 직행, 자동 확장, 복구와 누적 2점 검수 규칙은 유지한다.

## 화면 읽기

`전체 보기`는 10개 대분류의 흐름을 한눈에 보여 준다. `분야 확대`는 선택한 분야를 읽을 수 있는 크기로 확대하고 가로 위치를 맞춘다. 확대와 축소는 재생 장면을 초기화하지 않는다.

카테고리명과 상품·점수는 설명을 위한 가상 예시다. 특정 쇼핑몰의 공식 분류표, 의약품 판매 시스템, 실제 모델의 추론 결과를 재현한 것은 아니다.

## 확인 결과

10개 대분류, 중복 없는 분류 노드 66개, 최종 바스켓 38개, 가상 상품 500개를 확인했다. 2026-10-29 단계별 모델 정책을 적용한 기본 설정의 마지막 장면은 분류 완료 338개·사람 검수 162개이며, 모든 최종 분류에 도착한 상품이 있다. 이는 가상 규칙의 동작 결과이며 모델 정확도가 아니다.

기존 텍스트 우선·직행·판매자 보강·복구 점수 검사와 새 분류 트리 검사까지 5개 스크립트가 통과했다. 이후 단계별 정책 검사까지 추가해 현재는 총 6개 스크립트가 통과했다. 상품과 경로·바스켓의 연결, 같은 부모 아래 형제 분류, 상품 수 보존, 단일 노드의 표시 겹침, 직행 화살표와 도착 위치를 대조했다. 실제 브라우저에서 첫 화면, 분야 확대, 전체 보기, 재생·정지 및 390×844 모바일 화면을 확인했다.
