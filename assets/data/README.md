# 토큰 단가 그래프 원자료

- 원자료: [LLM API pricing history — Gravity](https://gravity.fast/data/llm-api-price-history/#price-by-tier), Aryan Agarwal.
- CSV: [Gravity data.csv](https://gravity.fast/data/llm-api-price-history/data.csv).
- 보관본: `llm-token-price-history-2026-10-28.csv` — 원본 값과 빈칸을 보존한 114행, 38개 시점, 3개 성능 기준.
- 자료 기준일: 2026-10-28. 직접 확인·보관일: 2026-10-29.
- 라이선스: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). 변경: 한국어 설명·반응형 SVG로 재시각화. 원본 사이트 스크린샷과 코드는 사용하지 않았습니다.

각 시점에 LMArena 성능 기준을 충족한 모델 중 가장 저렴한 표준 종량제 API의 혼합 단가입니다. 입력 3 : 출력 1, 미국 달러 / 100만 토큰, 세로축 로그 눈금입니다. 같은 모델 제품의 가격 추이나 모든 업무의 동등 성능을 뜻하지 않습니다. 성능 구분은 원자료의 2026-10-02 텍스트·스타일 보정 종합 점수를 따릅니다.

`blended_usd_per_1m` 열의 공개 값을 그대로 사용합니다. 예를 들어 0.0703을 입력·출력 값으로 재계산한 0.07025로 바꾸지 않습니다. 빈칸은 관측값 없음이며 0이 아닙니다. 관측값을 날짜 비례로 연결하며 상승 구간도 유지하고 미래 시점은 그리지 않습니다.

GPT-4 수준의 비교는 2023-10-01 $37.50 → 2026-10-28 $0.0575입니다. 약 652분의 1, 99.85% 감소(화면에서는 99.8%)입니다. 다른 성능 기준의 최신 단가는 GPT-4o 수준 $0.0703, Gemini 2.5 Pro 수준 $0.1525입니다. 개별 가격을 과제의 실측 처리비용이나 652배 생산성 향상으로 해석하지 않습니다.

원자료는 11개 모델 회사와 6개 추론 제공처를 포함합니다. Google API는 2024년 10월 이전 가격 기록이 빠져 있습니다. 무료·배치·우선 처리·긴 문맥 요금은 제외하며 추론 토큰 등 실제 사용량에 따라 업무당 비용은 달라집니다. 장기 하락에 대한 사이트의 문구는 설계자의 전망이며 보장이나 실측 미래 데이터가 아닙니다.
